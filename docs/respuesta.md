| 1 | **Acepta** | En `css/estilos.css`, el bloque `@media (min-width: 900px)` define el diseño de las tarjetas antes de las reglas base. Como ambas usan selectores con la misma especificidad, prevalecen las reglas base que aparecen después. Por eso, el breakpoint no aplica el cambio esperado. | **Antes:** las reglas del breakpoint quedan sobrescritas por las declaraciones `flex-basis: 300px` y `280px`. **Después:** mover el bloque del breakpoint después de las reglas base o ajustar su especificidad y verificar el diseño a ambos lados de los 900 px. | hacer efectivo el breakpoint de 900px |
| 2 | **Acepta** | En modo oscuro, `--color-primario: #0a9396` se usa como fondo de encabezados de tabla, botones y enlaces del menú al pasar el cursor. Con texto blanco, el contraste es 3,73:1, inferior al mínimo de 4,5:1 para texto normal establecido por WCAG 2.2, criterio 1.4.3. | **Antes:** texto blanco sobre fondo `#0a9396` en modo oscuro. **Después:** usar un fondo más oscuro que alcance al menos 4,5:1 de contraste con el texto blanco y comprobar los componentes afectados. |mejorar contraste de componentes en modo oscuro |
| 3 | **Acepta** | Los campos del formulario usan un borde `#444444` sobre fondos oscuros. El contraste no alcanza 3:1, requerido por WCAG 2.2, criterio 1.4.11, cuando el borde es necesario para identificar el componente. | **Antes:** los controles usan `border: 1px solid var(--color-borde)` y el tema oscuro define `--color-borde: #444444`. **Después:** aclarar el borde o usar otro indicador visible que alcance al menos 3:1 respecto al color adyacente. |aumentar contraste de bordes de formulario |
| 4 | **Refuta** | El campo `range` no muestra un número junto al control, pero sí tiene una etiqueta asociada. WCAG 2.2, criterio 3.3.2, requiere etiquetas o instrucciones cuando se solicita información; no exige por sí solo añadir un elemento `<output>` para este campo. Mostrar el valor seleccionado sería una mejora de usabilidad, no un incumplimiento demostrado por la norma citada. | **Antes:** el campo tiene etiqueta, `min="1"`, `max="10"` y `value="2"`, pero no muestra el valor numérico. **Después:** no se requiere un cambio para corregir el incumplimiento alegado. | mejora opcional |
